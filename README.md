# Winspot

Professional macOS Spotlight-inspired search tool for Windows — optimized for speed, accessibility, and daily use.

## ✨ Features
- **⚡ Blazing Fast**: WinRT API + disk cache for near-instant repeated searches
- **🎯 Smart Prioritization**: Learns your habits — frequent apps appear first
- **🖼️ Semantic Icons**: Instantly see file types (📄 PDF, 🖼️ JPG, ▶️ MP4, etc.)
- **♿ Accessibility**: WCAG 2.1 AA compliant high-contrast mode (toggle via tray)
- **👀 Result Previews**: Hover over files/folders to see full path
- **📋 Clipboard Feedback**: "✓ Copied!" confirmation for math results
- **🎙️ Voice Search**: Alt+K toggles Windows Dictation (100% offline)
- **💾 Low-End Optimized**: Smooth animations on powerful PCs, instant on weak hardware
- **🧮 Math Solver**: Type `2+2` → press Enter to copy result
- **🌐 Web Search**: Prefix with `?` for instant Google search
- **📎 System Tray**: Right-click to show/hide or quit
